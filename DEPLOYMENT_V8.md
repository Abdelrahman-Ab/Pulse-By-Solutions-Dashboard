# Vercel Deployment v8

This package is based on the approved Local v8 dashboard.

Approved changes retained:
- Partners Leads shortcut is located at the bottom-right of Order Book Analysis Global Filters and uses the secondary color.
- Partners Leads collects Opportunity IDs from Opportunities where Roadmap = Won and Channel = Partner, then applies those IDs through the existing Order Book Opportunity ID filter.
- List of Opportunities uses its original Opportunities values for Actual Opp Value and Actual Opp Value Margin; the prior Order Book value substitution was undone.
- All other approved dashboard behavior remains unchanged.

Local-only files have been omitted from this deployment package.
