## Data sources
Refresh Data now uses five configured workbooks: Opportunities, Order Book, Targets, Purchase Order Details, and Strategic Partners. Purchase Order Summary has been retired; its required relationship data is derived from Purchase Order Details.

The Strategic Partners workbook controls the Strategic Partners shortcut; the actual Partners Performance values are calculated from Purchase Order Details.
