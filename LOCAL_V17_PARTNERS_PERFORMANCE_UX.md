# Local v17 — Partners Performance + UX refinements

- Adds **Partners Performance** with 20 searchable single-partner selectors and 20 corresponding PO SAR graphs.
- Strategic Partners button refreshes its list from the dedicated Strategic Partners workbook.
- Partner matching is case-insensitive and uses the first word of Vendor Name.
- Partner graphs cover 2020–2026 and show Egypt, KSA, Growing Markets, and Total with fixed series colors.
- Numeric chart axes scale dynamically using clean rounded 1/2/5/10 × powers-of-ten steps.
- Date hierarchy years are newest-first; quarter/month ordering is unchanged.
- Selected filter values appear first when filters are reopened.
- `Unassigned` is removed from selectable/searchable filter options.
- Desktop/laptop browser zoom no longer causes the main navigation to wrap; it scrolls horizontally only when necessary.
- Partner data is aggregated/cached once per snapshot, and partner option lists are rendered only for the selector currently open to keep the new section responsive.
