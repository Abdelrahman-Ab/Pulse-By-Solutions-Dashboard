# Vercel v30 — Clickable Opportunities Analysis pie charts

Small interaction update only.

- Pipeline Per Sector Distribution is now clickable and cross-highlights the related
  Opportunity data using Sector.
- All Market Units / Market Unit Distribution is now clickable and cross-highlights
  related data using Market Unit.
- Opportunity Types remains clickable as before.
- Click the same pie slice again to clear the cross-highlight.
- Pie highlight overlays no longer block pointer clicks.
- Clickable pie slices and their callout labels now use a pointer cursor.

All v29 data logic, Active Pipeline Progress, filters, calculations, favicon fix,
and deployment architecture are unchanged.

The deployment ZIP intentionally excludes .git metadata.
